# 軽量カメラ（CompactCapture）

[English](README.md) | **日本語**

iPhone／iPadで、保存容量とピクセル表現を自分で制御しながら写真・動画を撮影するカメラアプリです。

UIは日本語と英語に対応しています。

## 今回の主な機能

- 設定の保存
  - 写真／動画、解像度、FPS、保存形式、ビットレートを保存
  - 共通の「色の細かさ」（RGB各色の段階数）、コントラスト、出力倍率を保存
  - 「写真アプリにも保存」のON／OFFを保存（初期値OFF）
  - ISO・シャッターの固定状態と数値、露出補正を保存
  - ホワイトバランスと補正も保存
  - 撮影ズーム倍率も保存
  - 現在の撮影設定へ名前を付け、複数のプリセットとして保存・同名更新・呼び出し・削除
- 撮影ズーム
  - 対応端末では0.5×の超広角から望遠側まで利用
  - 0.5× / 1× / 2× / 3× / 5× / 10× / 15×を基準に、端末のレンズ構成へ合わせた最大7個の代表倍率を表示
  - 最大倍率を15×に抑え、代表倍率は横スクロールなしで画面内へ配置
  - 代表倍率ボタンは即時切替、撮影画面のピンチ操作は連続微調整として利用
  - レンズ境界付近で物理レンズが頻繁に往復しないよう切替幅を調整
  - 超広角・広角・望遠の物理レンズを切り替え、ISO・シャッターの手動設定を維持
  - 写真と動画で共通して使用し、動画録画中は現在のレンズ内で連続ズーム
  - 倍率範囲とレンズボタンは端末のカメラ構成に合わせて自動調整
- 見分けやすい設定画面
  - 項目ごとにSF Symbolsのアイコンと薄いカテゴリ色を表示
  - 選択肢にも用途に応じたアイコン、選択マーク、色付き枠を表示
  - 一画面内に収めながら各設定行と画像サイズ欄を高くして操作しやすく表示
  - 設定項目を画面下側へそろえ、最下段全体を大きな「撮影へ」ボタンとして操作
  - 設定画面でもカメラを動かし続け、空いた上部のライブ映像へ画像サイズ、色の細かさ、コントラストなどを即時反映
  - ライブ映像を隠さないよう、プレビュー上部の説明と設定要約は表示しない
  - 設定項目はすりガラスのぼかしを使わず、透明度の高い単色背景と暗い文字縁取りでライブ映像上の可読性を確保
  - 写真・動画の画像サイズは、どちらも大きい順から小さい順に配置
  - 2段の画像サイズ欄は、各ボタンを押しやすい高さで表示
- 見通しのよい撮影画面
  - 撮影画面上部の状態メッセージと「保存結果の目安」を非表示にし、ライブ映像の表示領域を確保
  - 下部の撮影パネルとズーム欄は、すりガラスのぼかしを使わず、透明度の高い単色背景と細い輪郭線を使用
  - 前回撮影した実ファイル容量は撮影画面へ残さず、写真・動画の詳細画面で確認
  - 録画中と処理中の状態だけは撮影パネル内へ表示
- 端末方向に合わせた保存
  - 撮影画面は縦向きのまま維持
  - 写真はシャッターを押した時点の端末方向を反映し、縦向き・左右の横向き・上下逆向きで保存
  - 動画は録画開始時点の端末方向を最後まで固定し、再生時も正しい向きで表示
  - 動画一覧の解像度表示も、保存方向に合わせて縦横を記録
- アプリ内写真・動画一覧
  - 写真・動画をアプリ専用領域へ保存し、権限なしで一覧・再生
  - 使用容量を一覧下部へ表示
  - 一覧・詳細表示とも最下段全体の「撮影へ」で撮影画面へ復帰
  - 詳細表示で解像度、動画の再生時間、保存後の実ファイル容量を表示
  - 写真のズーム操作と動画の再生・ズーム操作を、最下段の「撮影へ」専用領域より上へ配置
  - 詳細画面からアプリ内データを個別削除
  - バージョン1.7より前に写真アプリへ保存したデータは写真アプリ側に残るが、アプリ内一覧の対象外
- 設定ごとの容量目安
  - 写真は、容量に影響する選択肢の下段へ1枚あたりの推定容量を表示
  - 写真は解像度、保存形式、圧縮品質、色の細かさ、PNGの出力倍率を反映
  - 動画はビットレートと「音声あり／なし」の行だけに1分あたりの推定容量を表示
  - ProRes 4444ではビットレート行へ自動推定値を表示
- 写真・動画の連続確認
  - 詳細画面を左右にスワイプして前後の写真・動画へ移動
  - 動画は等倍時にページ送り、拡大時だけ映像内の移動へ自動で切り替え
  - 前後ボタンでも移動可能
  - 詳細画面最下段の「撮影へ」から、一覧を経由せず1回で撮影画面へ戻る
- ピクセルをぼかさない写真確認とズーム
  - 表示補間を最近傍に固定
  - ピンチ操作、ダブルタップ、縮小／拡大、1×／2×／4×／8×／16×ボタン
- 動画再生とズーム
  - アプリ内で再生／一時停止、再生位置変更
  - ピンチ操作、ダブルタップ、縮小／拡大、1×／2×／4×／8×ボタン
- 整数倍保存
  - 低解像度化と減色を先に処理し、その完成ピクセルを最近傍法で拡大
  - 1×／2×／4×／8×／16×を選択
  - 写真ではPNGだけに適用。JPEG／HEIFでは論理解像度のまま保存
  - 動画では選択したコーデックへ渡す直前に同じ処理を適用
  - 写真は最大48 MP、動画は4K相当以内になる倍率だけ選択可能
- 写真と動画の共通設定
  - 色の細かさ、コントラスト、出力倍率は写真・動画で同じ値を共有
  - 撮影種別を切り替えても共通値を引き継ぐ

## 写真

- HEIF／JPEG／PNG
- 初回起動時の保存形式はPNG
- 最大、12／8／4／2／1／0.5／0.25／0.10／0.05／0.025 MP
- RGB各色を標準、64、32、16、8、4段階へ量子化
- コントラストを「低／弱／標準／強／高」の5段階で調整
- JPEG／HEIFの圧縮品質を変更
- PNGを1×／2×／4×／8×／16×で最近傍拡大して保存
- 保存後の実ファイルサイズを表示

PNGは無圧縮形式ではなく可逆圧縮形式です。「4段階/色」はRGB各色を4段階にするため、組み合わせは最大64色です。画像全体を4色だけにする処理ではありません。

設定画面では一般向けに「色の細かさ」と表示します。標準はRGB各色256段階（8 bit）、64段は6 bit、32段は5 bit、16段は4 bit、8段は3 bit、4段は2 bit相当です。

写真の推定容量は一般的な画像内容を仮定した概算です。特にPNGは絵柄やノイズ量による差が大きいため、撮影後の詳細表示に出る実ファイル容量を最終値として確認してください。

## 動画

- 論理解像度
  - 4K、1080p、720p、0.5 MP、480p、0.25 MP、240p、180p、160×90
- 5／10／15／24／30 fps
- HEVC（H.265）／H.264
- 対応端末ではProRes 4444を追加表示
- HEVC／H.264は0.5／1／2.5／5／10 Mbps
- 写真と共通のRGB各色の段階数削減
- コントラストを「低／弱／標準／強／高」の5段階で調整
- 色差の標準／弱／強／モノクロ
- 音声あり／なしを2択で設定し、それぞれの推定容量を表示
- 公開APIとアプリ独自音源による、無効化できない録画開始音・終了音
- 開始音の再生完了後に録画を開始し、録画停止処理後に終了音を再生して動画内への混入を抑制
- 論理解像度で縮小・減色した後、最近傍で整数倍してから動画エンコーダーへ入力

HEVC／H.264は非可逆圧縮なので、整数倍保存を使っても圧縮ノイズを完全には除去できません。ピクセル境界を優先する場合は、対応端末でProRes 4444を選びます。ただしProRes 4444は色の細かさを下げても容量が非常に大きくなります。

## 露出操作

露出モード選択欄はありません。ISOとシャッターをそれぞれ独立して固定します。

- ISO固定なし・シャッター固定なし
  - 両方をカメラが自動調整
- シャッターだけ固定
  - ISOをアプリが測光値へ追従調整
- ISOだけ固定
  - シャッターをアプリが測光値へ追従調整
- 両方を固定
  - 完全手動になり、露出補正をグレーアウト
- 固定していない項目の数値ボタンはグレーアウト
- 固定中は−1段／−1/3段／現在値／＋1/3段／＋1段で変更
- 現在値を押すと詳細画面を開き、段階操作と連続対数スライダーを切り替え可能
- 露出補正の現在値を押すと0 EVへ戻る

## ホワイトバランスと補正

- ホワイトバランス
  - 自動／晴天／曇天／日陰／電球／蛍光灯
  - 色温度と色かぶりの手動調整
- 補正を個別設定
  - 手ぶれ補正
  - レンズ歪み補正
  - HDR
  - 低照度ブースト
  - 質感加工を最小化

通常のiPhone写真・動画では、センサーから保存データになるまでのISP処理を完全には停止できません。本アプリは公開APIで制御できる範囲でHDR、低照度処理、合成、高品質優先処理を抑えます。

## 撮影前の結果確認

- 保存結果に近いライブプレビューを常時表示
- 選択した論理解像度、色の細かさ、コントラストを反映
- 整数倍保存時の実保存解像度は設定項目内の各倍率で確認
- 画面表示の補間は最近傍
- 設定画面でもカメラを停止せず、最新フレームへ設定変更結果を連続反映
- 0.05 MPなどの低解像度も、論理解像度の画素数を過度に縮めずにプレビュー
- 物理レンズ切替時は切替直後の不安定なフレームを除外し、表示方向を縦向きへ固定
- 保存する写真・動画の方向は、iOS 17のカメラ回転コーディネーターから取得した撮影時の重力方向を使用

JPEG／HEIF／HEVC／H.264の圧縮ノイズはライブプレビューには含まれません。圧縮後の状態は実際に保存したファイルで確認します。

## 写真ライブラリ権限

- 通常はアプリ内だけに保存し、写真ライブラリ権限を要求しない
- 設定の「写真アプリ」をONにした場合だけ、撮影時に追加専用権限を要求
- 詳細画面の写真追加ボタンから、選んだ写真・動画だけを後から写真アプリへ保存可能
- 読み取り権限は使用しない
- ONの場合はアプリ内と写真アプリの両方に保存されるため、同じ写真・動画がそれぞれ容量を使用
- アプリ内データを削除しても、写真アプリへ同時保存したコピーは削除されない
- アプリを削除するとアプリ内だけに保存した写真・動画も削除されるため、残したいデータは「写真アプリ」をONにして撮影するか、詳細画面から後で保存する

## iPhoneカメラの制約

- 絞りは各レンズで物理的に固定されており、アプリから変更できません。
- ISO／シャッターの範囲は端末と選択形式によって変わります。
- 片側固定時の追従は本アプリによる制御です。急な明暗変化では追従に時間がかかり、端末の上下限では目標露出に届かない場合があります。
- 動画のシャッター上限は選択FPSにも制約されます。
- ProRes 4444は実行時に対応が確認できた端末だけに表示します。
- 高解像度、ProRes、フレーム変換、整数倍保存は発熱やフレーム落ちを増やす場合があります。
- 動画録画中は映像の途切れを避けるため物理レンズを切り替えません。超広角など別レンズを使う場合は録画開始前に倍率を選びます。
- 独自のAVAssetWriter録画を維持し、Appleの非公開音源を使わず、アプリ独自の開始／終了音と赤い点、ボタン形状、状態表示で録画状態を明示します。

## 開き方

1. Macで `CompactCapture.xcodeproj` を開きます。
2. ターゲット `CompactCapture` の Signing & Capabilities で自分のTeamを選択します。
3. Bundle Identifierが他のアプリと重複する場合は変更します。
4. 実機iPhoneを選択して実行します。カメラ撮影はSimulatorでは確認できません。

## ビルド条件

- iOS 17.0以降
- SwiftUI + AVFoundation（写真アプリへの任意追加時のみPhotos）
- iPhone・iPadともに縦向きを基本とし、iPadOSが画面を横向き・リサイズした場合もプレビュー方向を追従。背面カメラ（対応端末では超広角・望遠を含む）

写真マークを主役に、左の高解像度表現から右へ進むほど大きなピクセルへ変化する仮App IconをAssetsへ設定済みです。紺・黄緑・オレンジの3色だけを使用し、中間色やグラデーションは使用していません。1024×1024・アルファなしです。
